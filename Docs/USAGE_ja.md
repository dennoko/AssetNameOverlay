# Asset Name Overlay ユーザーガイド (USAGE_ja.md)

UnityのProjectウィンドウ上で、省略表示されてしまう長いアセット名をマウスホバー時にオーバーレイ（ポップアップツールチップ）としてフルネーム表示するエディタ拡張機能です。

## 使い方

### 1. アセット名を確認する
- Projectウィンドウで名前を確認したいアセットの上にマウスカーソルを移動させます。
- マウスカーソルの近傍に完全なファイル名が表示されます。
- アセットの領域からマウスを離すか、別の操作を行うと自動的に非表示になります。

### 2. 有効 / 無効を切り替える
- Unityの上部メニューバーから以下を選択します：
  ```
  dennokoworks > Asset Name Overlay > Enabled
  ```
- メニュー項目に **チェックマーク（✓）** が付いている状態が有効です。
- クリックするごとに有効 / 無効がトグル切り替えされます。
